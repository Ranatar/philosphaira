## Как поднять

**База обязана быть в локали, сворачивающей кириллицу** (`C.UTF-8`, `ru_RU.UTF-8`
и подобные). Единственность логина и почты держится на `lower()`, а в локали `C`
`lower('ИВАН')` возвращает `ИВАН` — и «ИВАН» с «иван» окажутся разными людьми.
Проверяет `auth_probe`; на голом `initdb --locale=C` он краснеет, и это не
придирка, а найденная ловушка.

```
createdb philos --locale=C.UTF-8 --template=template0
export DATABASE_URL='postgres://…/philos'
npm install
npm run migrate            # накат
npm run bootstrap-admin    # первый администратор
bash accept.sh             # приёмка: строение + база
```

## Правило, из которого следует остальное

**`rows[0]` не покидает `src/db/`.** Всё, что выходит наружу, прошло через
преобразователь; всё, что входит в службы, — доменный объект. Половина
дефектов первой редакции документа росла из того, что строка базы гуляла по
службам как объект: проверка прав спрашивала `isBanned`, а в строке лежало
`is_banned`, и ответ не зависел от состояния пользователя вовсе.

Стережёт это `structure_probe`, и он поймал нарушение при первом же
прогоне — в `bootstrap-admin.mjs`, написанном получасом раньше.
