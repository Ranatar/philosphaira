# Основания по первоисточникам: связи Витгенштейна (26–27 сентября 2026)

Файлы правок первого захода наполнения базы источниками. Применяются
программами `tools/edit/` по порядку заходов; повторный прогон любого файла
даёт «правок 0». У каждой записи ОДИН файл: общий прогон файлов, описывающих
одну запись дважды, откатывал бы поздние редакции ранними.

| Заход | Программа | Что |
|---|---|---|
| W1 | `fix_links.mjs` W1-fix | разворот Куна; атомизм → изображение переписан, вес 3 → 2 |
| W1 | `add_links.mjs` W1-add | три критики: атомизм → показывание, семейное сходство → функция и аргумент, языковые игры → атомизм |
| W1 | `set_provenance.mjs` W1-provenance, W1b-provenance | основания и сноски |
| W2 | `fix_links.mjs` W2-fix | удалены атомизм → логическое пространство и → границы языка; смысл и значение → изображение, вес 2 |
| W2 | `add_links.mjs` W2-add | изображение → атомизм (встречное влияние) |
| W2 | `set_provenance.mjs` W2-provenance | Кант, Джеймс, воля, уточнения |
| W3 | `fix_links.mjs` W3-fix | удалены обе «Мысль (Фреге) → …»; возможные миры → логическое пространство — в типологию |
| W3 | `add_links.mjs` W3-add | изображение противостоит мысли |
| W3 | `set_provenance.mjs` W3-provenance | основания к двум последним |

Причины удалений записаны в самих файлах (поле `reason`). Ход работы и
находки оснастки — в `doc/history.md`, раздел «Основания по первоисточникам».
Формат ссылок согласован с автором: TLP 2.172, PU §202,
PU II xi (Schriften 1, S. 539), TB 2.8.16.
