# Основания по первоисточникам: связи Витгенштейна (26–27 сентября 2026)

Файлы правок первого захода наполнения базы источниками. Применяются
программами `tools/edit/` по порядку заходов; повторный прогон любого файла
даёт «правок 0». У каждой записи ОДИН файл: общий прогон файлов, описывающих
одну запись дважды, откатывал бы поздние редакции ранними.
