# ΦilosΦaira в Termux на Android

## Сперва — что здесь работать не будет

Прежде чем ставить: часть проекта на телефон не переносится в принципе.

| Слой | В Termux | Почему |
|---|---|---|
| Сервер, страница, API, живые соединения | **да** | Node и PostgreSQL под Android есть |
| Приёмка сервера, 16 проб из 17 | **да** | им нужна только база |
| `page_probe` (17-я проба) | нет | поднимает Chrome |
| Приёмка приложения: 13 приборов, эталоны, полный обход | **нет** | всё это Chrome 131 через puppeteer |
| Пересборка из исходника (`remap.mjs собрать`) | формально да | но проверить её нечем — см. ниже |

Последняя строка важнее, чем кажется. Сборка на телефоне пройдёт: это чистый Node с acorn. Но правило проекта — «правка исходника заканчивается приёмкой» — на телефоне неисполнимо, а сборка без приёмки в этом проекте не считается сделанной работой. Значит **Termux годится для эксплуатации и не годится для разработки.** Держите телефон как второй узел, а правку исходника оставьте Ubuntu.

## Два места, где может не выйти вовсе

**Локаль.** Единственность логина и почты держится на `lower()`, и `РАСПАКОВКА.md` требует базу с локалью, сворачивающей кириллицу. В Android нет glibc, а `C.UTF-8` у bionic может оказаться пустой — тогда `lower('ИВАН')` вернёт `ИВАН`, и два разных человека заведутся под одним именем. Скрипт проверяет это прямой командой и при неудаче **останавливается**, а не идёт дальше молча. Запасной ход — ICU, если здешний PostgreSQL с ним собран; скрипт подскажет, как проверить.

**Пароль роли.** PostgreSQL 14+ требует пароль для соединений по TCP, а у роли, которую заводит `initdb`, его нет — попытка обратиться к базе через `127.0.0.1` даёт запрос пароля, которого не существует. Скрипт ходит служебными командами через сокет, где та же роль пускается по `peer`, и задаёт роли случайный пароль для `DATABASE_URL`; пароль лежит в `~/.philos.env`.

**`argon2`.** Он нативный, готовых сборок под Termux нет — собирается на месте, отсюда `clang`, `make`, `python` в списке пакетов. Обычно проходит, но небыстро: до десяти минут. Скрипт после установки проверяет, что модуль действительно грузится, — иначе вход и регистрация не заработают, а узнали бы вы об этом только при первой попытке войти.

Оба заслона стоят до того, как вы потратите время на остальное.

## Что нужно

- **Termux из F-Droid**, а не из Play Store: версия в Play заброшена и `pkg` в ней ломается.
- Android 7 и новее, arm64.
- 1,5–2 ГБ свободного места, из них около гигабайта — `node_modules` и сборка `argon2`.
- 3 ГБ ОЗУ и больше: PostgreSQL и Node вместе укладываются в 400–500 МБ, остальное съедает сам Android.

## Установка

Перекиньте `philosphaira.zip` в «Загрузки» телефона и в Termux:

```bash
termux-setup-storage          # один раз, разрешить доступ к памяти
pkg install -y curl
# положите philos-termux.sh в ~ любым способом
bash philos-termux.sh установить ~/storage/downloads/philosphaira.zip
```

Одна команда делает всё: пакеты, PostgreSQL, две базы (рабочую и испытательную), проверку сворачивания, распаковку, зависимости, ключ MFA, миграции, семя графа, **первую раскладку**, первого администратора и запуск **двух процессов** — узла и работника уведомлений. Пароль администратора спросит с клавиатуры, чтобы он не осел в истории оболочки.

Занимает это от пятнадцати минут до получаса, почти всё время — сборка `argon2`.

По завершении скрипт назовёт два адреса: `http://127.0.0.1:8814/` для самого телефона и адрес в домашней сети — по нему страница откроется с любого устройства в той же сети, включая ваш Windows 7.

**Сохраните `MFA_SECRET_KEY` из `~/.philos.env` вне телефона.** Потеряете ключ вместе с телефоном — потеряете все заведённые TOTP.

## Управление

```bash
bash philos-termux.sh пуск         # поднять базу и сервер
bash philos-termux.sh стоп         # остановить всё
bash philos-termux.sh состояние    # что работает, по какому адресу
bash philos-termux.sh журнал       # последние 40 строк
bash philos-termux.sh адрес        # только адреса
bash philos-termux.sh приёмка      # приёмка сервера на испытательной базе
```

**`пуск` поднимает ДВА процесса**, а не один: узел и работника уведомлений.
Без работника цепочка живого отклика рвётся на первом звене — коммит кладёт
извещение в исходящие, и оно там лежит; чужая правка не доходит до открытых
страниц вовсе. Прежняя редакция этой инструкции уверяла, что работник нужен
«только при настоящей почте», — **это была неправда**: извещение в шину идёт
до почты и независимо от неё.

Молчание работника — единственная беда, которую не видно на глаз: сервер
отвечает, страница работает, правки сохраняются. `состояние` показывает его
отдельно и заодно считает неразосланное в исходящих.

`приёмка` жёстко берёт `philos_test` и не смотрит, что у вас в окружении: `db_probe` откатывает базу до пустого места, и одна забытая переменная стоила бы вам рабочих данных. `page_probe` в этом окружении покажет красное — это ожидаемо, а не поломка.

## Три особенности Android

**Сон.** Система усыпляет фоновые процессы через несколько минут. Скрипт берёт `termux-wake-lock` при запуске и отпускает при остановке. Сверх того зайдите в настройки Android и уберите Termux из оптимизации батареи — иначе сервер будет умирать посреди работы.

**Автозапуск.** `systemd` в Android нет. Если нужен подъём после перезагрузки — поставьте **Termux:Boot** (тоже F-Droid) и положите туда однострочник:

```bash
mkdir -p ~/.termux/boot
printf '#!/data/data/com.termux/files/usr/bin/bash\ntermux-wake-lock\nbash $HOME/philos-termux.sh пуск\n' \
  > ~/.termux/boot/philos && chmod +x ~/.termux/boot/philos
```

**Порт.** Android не даёт занимать порты ниже 1024 без root — 8814 в этот запрет не попадает, ничего делать не нужно. Но адрес в домашней сети телефон меняет при переподключении к Wi-Fi: закрепите его в настройках роутера, иначе закладка перестанет открываться.

## Резервное копирование

```bash
pg_dump -Fc philos > ~/storage/downloads/philos-$(date +%F).dump
```

В «Загрузках» файл виден обычным файловым менеджером и уезжает на компьютер как всякий другой. Берегите ещё `~/.philos.env` — в нём ключ MFA.

## Разумная граница

Телефон как сервер хорош для одного: держать ΦilosΦaira при себе, читать и править граф с любого устройства дома, не поднимая виртуалку. Постоянным узлом для нескольких человек он не станет — Android рано или поздно убьёт процесс, а батарея не любит круглосуточного PostgreSQL. Как второй, карманный экземпляр — вполне.
