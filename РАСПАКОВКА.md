# ΦilosΦaira — как поднять снимок проекта

Многопользовательский режим доведён до конца плана: фазы 0–5, плюс
оформление новых панелей (глава стилей `11-multiuser`).

## Чего в архиве НЕТ и почему

| Не вошло | Почему |
|---|---|
| `node_modules/`, `server/node_modules/` | восстанавливается `npm install` |
| `.git/` | история остаётся в репозитории |
| `app/_ref-orig.html` | порождается `python3 tools/make_ref.py` за секунду |
| `tools/__pycache__/`, `*.pyc`, `*.log` | следы запусков |
| `server/.env`, `server/.env.local` | местные тайны; образец — `server/.env.example` |

`app/` ОСТАВЛЕН, хотя он и производное: это готовое к работе дерево.
Восстанавливается из исходника командой `node tools/remap.mjs собрать` —
но тогда сперва нужны зависимости.

## Подъём

```
npm install                     # зависимости приложения (приборы приёмки)
cd server && npm install

# База: локаль ОБЯЗАНА сворачивать кириллицу — единственность логина
# и почты держится на lower(), а в голой локали C 'ИВАН' не станет 'иван'.
createdb philos --locale=C.UTF-8 --template=template0

export DATABASE_URL='postgres://…/philos'
export MFA_SECRET_KEY="$(node -e "console.log(require('crypto').randomBytes(32).toString('base64'))")"
export BOOTSTRAP_ADMIN_PASSWORD='ваш-длинный-пароль'

npm run migrate            # схема
npm run graph:import       # семя графа — ОДИН РАЗ
npm run bootstrap-admin    # первый администратор — ОДИН РАЗ
npm start                  # http://127.0.0.1:8814/
```

`.env.example` — перечень переменных, а НЕ загружаемый файл: точки входа
читают `process.env` напрямую. Ключ второго шага сохраните: потеряете —
потеряете все заведённые TOTP.

`npm start` ничего не готовит: не накатывает миграций, не сеет граф, не
заводит людей. Повторный `graph:import` откажет — шесть JSON это семя, а
рабочее состояние живёт в базе.

Первый администратор получает настоящий пароль и подтверждённую почту, но
**второй шаг заводит сам**: до этого опасные права срезаны, включая
назначение второго администратора.

Сервер отдаёт и страницу, и API: страница, отданная им, несёт метку
`<meta name="philos-api">`, по которой клиент и узнаёт, что сервер есть.
Без метки страница работает как одностраничная — ровно как прежде.

## Приёмка

```
bash tools/accept.sh                    # приложение и сервер разом
bash tools/accept.sh --только-приложение
bash tools/accept.sh --только-сервер
bash tools/deploy_check.sh              # развёртывание с нуля, из клона
```

CHROME задавать НЕ надо: умолчание в `tools/paths.mjs` верно (Chrome 131,
которым учреждены эталоны). PUPPETEER — надо.

## С чего читать

1. `readme.md` — устройство сборки, приёмка, уроки. §10 — журнал заходов,
   §10-тер — многопользовательский режим, §8 — правила работы с приборами.

   части ПО ФАКТУ построенного; в конце — чем построенное разошлось
   с замыслом.
3. `server/README.md` — слои приёмки сервера.

## Главное утверждение

**Без сервера страница работает ровно как прежде.** Проверяется офлайн-
приёмкой; за фазы 0–4 ни один эталон не сдвинулся иначе как от добавленной
разметки, посчитанной поштучно.
